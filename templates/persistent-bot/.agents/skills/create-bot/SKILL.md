# Create bot

Choose a stable lowercase ID, a display name and a one-sentence mission. From the chief project run `python3 ../../codexos.py create-bot ID --name NAME --mission MISSION`, with each value supplied as a single quoted argument. Review the generated manifest and project with the operator. New sources, project registration and schedule activation require separate authorization. See the fleet guide for registration and recovery.
