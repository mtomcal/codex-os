# Reconcile work

Read the producer report from an approved local source and compare it to the workload's objective, criteria and prior evidence. Use the workload and commitment commands shown by `python3 ../../codexos.py --help`. Confirm completion against an approved artifact. If only a claim is available, record the observation and keep the commitment open.
